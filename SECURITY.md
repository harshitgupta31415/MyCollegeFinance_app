# Security and privacy policy

Security fixes target the current default branch.

Use GitHub's private vulnerability reporting for unintended disclosure of locally stored financial plans, unsafe deserialization, dependency vulnerabilities, or authentication/sync behaviour that bypasses user consent. Provide synthetic college and loan data only.

The current application stores planning data locally. Firebase packages do not imply that cloud sync is active. Any future sync feature must document encryption, access control, deletion, and data-retention behaviour before release.
